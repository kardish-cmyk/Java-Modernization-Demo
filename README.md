# Spring PetClinic – Modernization Demo

This repository is a snapshot of Spring PetClinic used for a Java and Spring Boot upgrade demo. It started as a frozen legacy baseline (Spring Boot 2.7.3, Java 8) and now runs on Spring Boot 3.5 and Java 21. It is not maintained.

Source: upstream commit `9ecdc11` of the original project, https://github.com/spring-projects/spring-petclinic

Build and test (JDK 21): `./mvnw verify` (JaCoCo coverage report: `target/site/jacoco/index.html`)
