# Spring PetClinic – Legacy Snapshot

This repository is a frozen legacy snapshot of Spring PetClinic (Spring Boot 2.7.3, Java 8), used as the baseline for a Java and Spring Boot upgrade demo. It is not maintained.

Source: upstream commit `9ecdc11` of the original project, https://github.com/spring-projects/spring-petclinic

Build and test (JDK 8): `./mvnw verify` (JaCoCo coverage report: `target/site/jacoco/index.html`)
